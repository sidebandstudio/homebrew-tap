# Clawtrate Homebrew tap

The Homebrew cask for [Clawtrate](https://clawtrate.dev), a free, open-source desktop app for OpenClaw. It installs the current Mac beta for Apple silicon or Intel from Clawtrate's GitHub releases and checks each download's SHA-256 before it installs.

```sh
brew install --cask sidebandstudio/tap/clawtrate
```
